# VANTMÈRE

A luxury streetwear marketing site built with Next.js, GSAP, Lenis, and React Three Fiber.

## Development

```bash
npm run dev     # start the dev server
npm run build   # production build
npm test        # run the test suite
```

## Documentation

Project specs and implementation plans live under `docs/superpowers/specs` and `docs/superpowers/plans`.
